# continue-with-{trae,qoder,workbuddy,zcode} 四个 skill 开发计划（全局安装版）

## Context

continue-with-opencode 已交付验证。用户要求按相同思路再实现 4 个 skill（Trae/Qoder/WorkBuddy/ZCode），并明确：**所有 skill 及目标工具侧的一键命令均默认全局安装**。

调研确认的各工具一键机制与全局命令目录：

| 工具 | 全局一键命令位置 | 关键约束 |
|---|---|---|
| Trae | `~/.trae-cn/commands/continue.md`（CN 版官方全局目录；国际版检测到 `~/.trae/` 时也装一份） | 命令模板无 `$ARGUMENTS`；会话库加密不可外部注入 |
| Qoder | `~/.qoder/commands/continue.md`（官方；CN 版检测到 `~/.qoder-cn/` 时也装一份） | CLI headless `qoder -p '/continue'`；deeplink 可预填对话；引用语法 `@file` |
| WorkBuddy | `~/.workbuddy/skills/continue/SKILL.md`（全局 skill，官方发现根确认） | 无 command 机制，skill frontmatter 含 `userInvocable: true` |
| ZCode | `~/.zcode/commands/continue.md`（官方 command 发现顺序含用户级） | `!` 注入不预执行（降级为 Bash 审批），正文须直接指示模型读文件 |
| OpenCode（存量迁移） | `~/.config/opencode/commands/continue.md`（官方全局目录；项目级会覆盖全局） | `!` 注入预执行，保留 |

## 统一设计

**打包侧（5 个 skill，全局安装）**：`~/.agents/skills/continue-with-<name>/` 实体 + `~/.zcode/skills/` 软链，任何项目可触发。

**目标侧一键命令（全局，一次安装全项目通用）**：命令内容通用化——指示模型「读取**当前项目**的 `.handoff/HANDOFF.md` → 核对 git → 按任务规划继续」。打包 skill 执行时检测全局命令：不存在则 `mkdir -p` 创建，存在但为旧模板则幂等更新；已就位则告知用户无需重复安装。

**项目内只写数据**：`.handoff/HANDOFF.md` + `.handoff/attachments/`（五 skill 共用同一格式，工具中性），建议加入 .gitignore。

**兜底形态**（全局命令缺失/失效时）：固定提示词「请完整读取 .handoff/HANDOFF.md，按其任务规划继续」——所有工具通用。

## 各 skill 差异化要点

### continue-with-trae
- Step 4：检测/安装 `~/.trae-cn/commands/continue.md`（实现时先抓官方 slash-commands 文档确认确切文件格式再落盘；`~/.trae/` 存在时同装国际版）
- Step 5：`trae-cn <项目>`（或 `trae`）→ 聊天框 `/continue`
- `references/trae-cheatsheet.md`：CLI、rules（`.trae/rules/`、AGENTS.md/CLAUDE.md 兼容开关）、commands 格式、`.agents/skills/` 自动加载（v3.3.44+ 双保险）、`#` 引用、CN/国际版差异

### continue-with-qoder
- Step 4：检测/安装 `~/.qoder/commands/continue.md`（frontmatter description 必填；`~/.qoder-cn/` 存在时同装 CN 版）
- Step 5：IDE 打开项目 → `/continue`；CLI `qoder -p '/continue'`；deeplink `qoder://aicoding.aicoding-deeplink/chat?text=<URL编码>&mode=agent` 预填对话；兜底 `@file .handoff/HANDOFF.md 请读取恢复上下文并继续`
- `references/qoder-cheatsheet.md`：CLI 参数、commands（用户级覆盖项目级）、rules/AGENTS.md、`@` 引用、deeplink、Quest、会话存储

### continue-with-workbuddy
- Step 4：检测/安装 `~/.workbuddy/skills/continue/SKILL.md`（frontmatter：name/description/`userInvocable: true`；正文读当前项目 `.handoff/HANDOFF.md`；幂等更新；安装时告知用户为全局修改）
- Step 5：WorkBuddy 打开项目 → 对话框 `/continue`
- `references/workbuddy-cheatsheet.md`：内嵌 CodeBuddy 引擎架构、skill 发现根、不写 `.workbuddy/memory/` 的原因、内嵌 cbc `--resume/-p`（标注实验性）

### continue-with-zcode
- Step 4：检测/安装 `~/.zcode/commands/continue.md`（frontmatter description + argument-hint；**不用 `!` 注入**，正文直接指示「用读文件工具读取 .handoff/HANDOFF.md」；`$ARGUMENTS` 保留）
- Step 5：`cd <项目> && zcode` → `/continue`
- `references/zcode-cheatsheet.md`：AGENTS.md、skill/command 发现顺序与 shadow 优先级、command frontmatter 键、`!` 降级行为
