# HANDOFF.md 格式规范

`HANDOFF.md` 是交接包的核心。读者是**对本项目零背景的接手模型**。写它的唯一标准：读完 + 核对 git 现状后，接手模型不需要再问交接文档本可回答的问题。

写作总原则：

1. **具体压倒概括**：写 `src/auth/login.ts:42`，不写"认证模块"。
2. **可执行压倒描述性**：任务条目动词开头，接手模型读完就能动手。
3. **决策必须带 why**：没有理由的决策会在交接后被推翻，返工成本最高。
4. **短**：整篇目标 <400 行。大体积证据进 `attachments/`，正文只留指针。
5. **环境需求必须可检测**：7.1 清单每条带幂等只读检测命令；**禁止记录任何密钥/token/密码的值**（文档可能随 git 入库）。

## 设备指纹算法（打包与接收两侧必须一致）

```bash
fid_os=$(uname -s | tr 'A-Z' 'a-z')
case "$fid_os" in mingw*|msys*|cygwin*) fid_os=windows ;; esac
fid_input="$(hostname)|$(whoami)|$fid_os|$(uname -m)"
if command -v sha256sum >/dev/null 2>&1; then
  fid=$(printf '%s' "$fid_input" | sha256sum | cut -c1-12)
elif command -v shasum >/dev/null 2>&1; then
  fid=$(printf '%s' "$fid_input" | shasum -a 256 | cut -c1-12)
else
  fid=$(printf '%s' "$fid_input" | python3 -c 'import sys,hashlib;print(hashlib.sha256(sys.stdin.buffer.read()).hexdigest()[:12])')
fi
echo "$fid"
